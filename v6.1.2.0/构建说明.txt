安全传输 v6.1.1.0 源码与交付包
================================

内容
----
根目录
  安全传输-安装程序-v6.1.1.0.exe    安装版（NSIS；静默安装参数 /S）
  安全传输-便携版-v6.1.1.0.exe     便携版（解压即用，关窗即退；数据写在 exe 旁的 Data\ 与 下载\）
  构建说明.txt                       本文件
源码\                              完整源码（不含 node_modules、release、dist）

环境要求
--------
Windows 10/11 x64，Node.js 18 及以上，npm 9 及以上

构建步骤
--------
1. 把 源码\ 解压到本地目录（建议 D 盘）
2. 在源码目录执行 npm install
3. 国内网络先设置镜像与缓存：
     $env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
     $env:ELECTRON_BUILDER_CACHE = 'D:\.securetransfer-build\ecache'
4. 打包：
     npm run dist:win
   产物在 release\：
     安全传输-安装程序-v6.1.1.0.exe
     安全传输-便携版-v6.1.1.0.exe

常用命令
--------
npm run dev        开发模式（Vite HMR + Electron）
npm run build      仅编译主进程 / 预加载 / 渲染层
npm run pack       只打包目录，不生成安装器

版本说明
--------
版本号为四位（x.y.z.w），在 package.json 的 version 与 build.buildVersion，
前缀统一小写 v。每次交付前必须递增版本号（按改动幅度决定）。改动加密协议
或数据结构时建议递增前两位；两端必须同版本或兼容版本才能互通，旧版本握手
会提示升级。

加密说明
--------
强度档位：64 / 128 / 192 / 256 / 512 / 1024 位，默认 256。
  128 / 192 / 256 位为单层 AES-GCM，走 AES-NI 指令集；
  64 位为兼容通道，密钥材料经 HKDF 扩展为单层 AES-128-GCM；
  512 / 1024 位拆成 2 / 4 段 256 位密钥做级联 AES-256-GCM。
自定义密钥：PBKDF2-SHA512（21 万轮、固定盐）派生种子，与 ECDH 结果一起经
  HKDF-SHA512 派生双向会话密钥。留空走默认 X25519 ECDH 握手。
密钥落盘：本机密钥种子经 Windows DPAPI（Electron safeStorage）加密后写入
  settings.json / contacts.json，不保存明文口令。

加密协商（v6.0.0.0 起）
--------
连接时以「被连接方」配置为准：发起方先按自己记的好友密钥/强度握手，被连接
方检查不一致时回 NEGO 通知，发起方自动换对方密钥与强度重试（最多 3 次）。
  双方都设密钥、强度不同 → 连谁用谁的（发起方改用对方的强度与密钥）。
  一方有密钥一方没有 → 默认用无密钥那方（被连接方）的配置；有密钥方在添加
  好友时填对方的密钥即可，无密钥方什么都不用填。
  添加好友弹窗与聊天框顶部均有强度选择器；双方强度不同时聊天框顶部显示
  备注「对方 X 位 · 我方 Y 位」（从小到大），可随时切换。
修改或清除已设密钥必须输入旧密钥验证，验证通过才生效。

好友关系（v5.3.0.0 起）
--------
添加好友改为申请-同意流程：发起方建立加密通道后发送好友申请，对方在
「申请列表」中同意后双方才互为好友并建立连接。非好友无法互发文字与文件，
也不会被自动持久化为联系人。互为好友后，文件与语音到达即自动接收，
不再弹二次确认。申请提交成功显示绿色提示，失败才显示红色。

缓存目录
--------
统一缓存位于数据目录 cache\（安装版 %APPDATA%\安全传输\cache，便携版
Data\cache）：parts\ 断点续传分片、voice\ 语音临时文件、logs\ 运行日志，
以及 outbox.json（未送达消息）与 transfers.json（传输记录）。设置「运行」
页可查看占用并一键清理；清理会丢弃未送达消息与未完成的传输。
便携版所有数据只写在 exe 所在目录（Data\ 与 下载\），不触碰 C 盘。

断点续传与发送机制
--------
发送中断后保留分片记录，重连自动续传；数据已全部发出但完成通知丢失时，
重连后自动补发完成通知，不会卡在 99%。
文件发送沿用 v5.4.1.0 机制：点发送立即推进待发列表，离线或非好友时该次
发送给出失败传输行与提示「对方不在线，文件未发送」，不清空剩余待发文件，
也不弹「本次已取消」。文本消息照旧进 outbox 排队，对方上线后自动送达。

传输提示与传输中心（v6.1.1.0 起）
--------
发送失败提示（语音/文件）直接落在聊天消息流里，像一条消息一样跟着内容
滚动，不固定在输入框上方；只停留约 8 秒自动消失，也可点 × 手动关闭。
断点续传（等待续传 / 正在传输 / 已完成）仍固定在聊天框下方，可点 ×
手动隐藏且不会自动消失；有新的断点或传输进程时自动重新展开。
窗口栏右上角新增「传输中心」按钮（在线标志左边），打开后列出全部断点
续传进程与进行中的传输（含正常发送中的），以及最近的完成 / 失败记录。

物理引擎（v6.1.0.0 起）
--------
设置新增独立「物理引擎」栏，默认关闭。开启后所有光影（含 Liquid Glass
高光、波纹、光尘）由内置轻量 2D 物理模拟实时驱动：光源球受重力、惯性、
阻尼与边界反弹，点击界面任意位置会给它一个冲量（反弹触感）。
可调项：光源位置（水平/垂直）、Liquid Glass 材质（标准玻璃/磨砂/液态
金属/果冻）、反弹触感、反弹速度、波纹强度、光尘数量、黏稠度、重力。
页内带可点击的 Liquid Glass 预览（点击荡起波纹）。
窗口最小化 / 最大化 / 还原三动画始终走系统原生，不受物理引擎影响。

外观页（v6.1.0.0 起）
--------
顺序：预览（置顶，下滑仍可见）→ 主题模式（深浅四选）→ 窗口控制键
（macOS / Windows 滑块）→ 最大化时隐藏任务栏 → 背景颜色与调节滑块。
「毛玻璃强度」更名为「Liquid Glass 强度」，玻璃高光保持不变。
窗口控制键 = Windows 时：窗口右上角使用系统原生三键（动画与贴边行为全部
系统原生），置顶 / 在线 / 齿轮挪到左边（齿轮最左、在线中间、置顶靠右）。
窗口控制键 = macOS 时：左侧自绘红绿灯，布局与旧版一致。
「最大化时隐藏任务栏」开启后，点最大化铺满整个屏幕（覆盖任务栏）。

图标说明
--------
应用图标为浅蓝底 + 蓝白渐变白盾 + 中心高光 + 轮廓，空态 logo、任务栏、
托盘与静态 icon.png / icon.ico 保持一致风格。

其他说明
--------
深色模式四种（手动浅色 / 手动深色 / 跟随系统 / 跟随时间 19:00–07:00），
只在原有配色上整体压暗，不改用户背景色与主题色。任务栏/托盘图标底色取
主题色，盾牌按底色明暗自适应（底深白盾、底浅深盾）。默认开机自启并最小化
到托盘（设置「运行」页可关）。透明边距（悬浮阴影）的点击穿透由主进程轮询
光标位置控制，鼠标移回 UI 区域即自动恢复，不会出现窗口无法操作的情况。

传输提示与传输中心（v6.1.1.0 起）
--------
语音 / 文件发送失败提示改为聊天消息流内的居中标注：像消息一样随滚动移动，
不固定在输入框上方，8 秒后自动消失，可手动 × 关闭。
断点续传条固定显示、不自动消失，但可手动隐藏（×），隐藏后出现折叠条
「N 个传输进行中」，点击可恢复。
窗口栏右上角「在线」标志左边新增「传输中心」入口：面板显示所有断点续传
进程与正在发送的正常传输（进行中 / 断点续传 + 最近完成 / 失败）。

Liquid Glass 厚度与折射（v6.1.2.0 起）
--------
物理引擎新增「玻璃厚度」与「折射强度」两个可调项：
· 玻璃厚度：凸透镜的中心凸起与边缘厚度感（边缘变厚吸光 + 内缘高光细线）。
· 折射强度：透过玻璃看到的背景弯曲程度与彩虹色散（Snell 折射近似）。
开启物理引擎后，全屏挂载 WebGL2 折射层：凸透镜折射、色散、镜面高光、
波纹、光尘全部由 GPU 逐像素（fragment shader）渲染；CPU 只维持光源球
质点动力学（每帧几十次乘加，可忽略）。无 WebGL2 时自动回退 CSS 光影。
设置页 Liquid Glass 预览同样走 GPU 渲染，点击预览可模拟点击波纹。
