安全传输 — 源码运行说明
=======================

一、两种使用方式
1. 普通用户：直接运行“安全传输-安装程序.exe”，安装后从桌面快捷方式启动，无需安装 Python。
2. 源码运行：本机安装 Python 3.10+，双击“启动.bat”（首次会自动安装依赖）；
   或手动执行：pip install -r requirements.txt，再运行 python secure_transfer.py。

二、加好友（无服务器，数据只存本机）
1. 每个人有固定 ID（界面左上角，安装后生成，永不变），显示名称可随意改、允许重名，靠 ID 区分人。
2. 双方都打开软件后，一方点“添加/配对好友”，输入对方 IP:端口（端口默认 50090）。
3. 对方弹窗确认即配对成功，ID、名称、地址自动存入本地 contacts.json。
4. 同一 ID 换地址连入时会自动更新地址，不会重复添加。

三、在线状态与发送
- ● 在线：加密通道已建立，可发文字和任意文件，消息依次显示〔发送中〕〔发送成功〕〔已读〕小标签；
- ○ 离线：发送会弹出红色失败提示，不会丢进“假发送”，点“连接”等变 ● 后重发即可。
- 文件支持拖入窗口、文件管理器选择、粘贴本地路径或 http(s) 网址；接收文件在
  安装版：C:\Users\<你>\AppData\Local\安全传输\接收文件
  源码版：源码目录下的 接收文件 文件夹
- 文件原样传输、不压缩不转码；文字先经豪密层（底本+乱码表，握手时自动交换）再经 AES-256-GCM。

四、网络说明
- 同一局域网直接填对方局域网 IPv4 即可。
- 跨网络：双方有公网 IPv6 可直连（填 IPv6:端口）；IPv4 公网需在路由器做端口转发；
  首次运行若弹出 Windows 防火墙提示，请选“允许访问”。
