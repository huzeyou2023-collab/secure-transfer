安全传输 V3.3 — 使用说明
========================

一、三种使用方式
1. 安装版：运行“安全传输-安装程序.exe”，桌面与开始菜单生成快捷方式，无需 Python；
   用户数据存 C:\Users\<你>\AppData\Local\安全传输，卸载不删数据。
2. 便携版：本文件夹内的“安全传输.exe”双击即用，settings、contacts、接收文件
   全部生成在 exe 同目录；删除整个文件夹即彻底卸载，不留残留。
3. 源码运行：Python 3.10+，双击“启动.bat”自动装依赖并启动；
   或 pip install -r requirements.txt 后运行 python secure_transfer.py。

二、加好友（无服务器，数据只存本机）
1. 每个人有固定 8 位 ID（资料卡上，生成后永不变），显示名称可改、允许重名，靠 ID 认人。
2. 双方都打开软件，一方点“＋ 添加 / 配对好友”，输入对方 IP:端口（默认 50090）。
3. 对方弹窗确认即配对成功，ID、名称、地址自动存入本地 contacts.json。
4. 同一 ID 换地址连入自动更新地址，不会重复添加。

三、在线状态与发送
- ● 在线：加密通道已建立，可发文字和任意文件，消息依次带〔发送中〕〔发送成功〕〔已读〕小标签；
- ○ 离线：发送会出现明显的红色失败提示，内容不会假发出，选中好友点“连接”，变 ● 后重发。
- 文件支持拖入窗口、点“发送文件”选择、输入本地路径或 http(s) 网址回车；
  接收文件落在“接收文件”文件夹（便携版在 exe 同目录，安装版在 AppData\Local\安全传输）。
- 文件原样传输、不压缩不转码；文字先经豪密层（底本+乱码表，握手时自动交换），
  全部流量再经 AES-256-GCM 加密。
- 断点续传：传输中意外断开或关闭，双方自动保留进度；下次连接、协议握手完成后
  自动从断点继续传完，已传部分不重发；源文件被删除或改动则提示并取消该任务。

四、界面
- 四套配色：马卡龙（淡，默认）/ 极简（白灰白黑）/ 鲜艳（高饱和）/ 轻奢（白金、金色光带），左侧一键切换。
- 无边框窗口，四角为自绘抗锯齿超椭圆（高分辨率/16K 下依旧平滑），Liquid Glass 玻璃质感
  与新拟物 3D 凸起按键：拖动标题栏移动，双击标题栏最大化，拖窗口边缘八向缩放。
- 右上角三个按钮（Windows 顺序）：绿色最小化、黄色最大化/还原、粉色关闭。
- V3.3 起最小化、最大化、还原全部使用 Windows 原生窗口行为，不再使用自绘动画；
  并对不同电脑、不同屏幕缩放做了显示适配，长名称自动截断，界面不再错位。

五、网络说明
- 同一局域网直接填对方局域网 IPv4 即可。
- 跨网络：双方有公网 IPv6 可直连（填 IPv6 地址加端口）；IPv4 公网需在路由器做端口转发。
- 首次运行弹出 Windows 防火墙提示，请点“允许访问”。
- 安装包未做数字签名，SmartScreen 可能提示，选择“更多信息 → 仍要运行”。
