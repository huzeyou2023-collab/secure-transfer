安全传输（SecureTransfer）
=========================

局域网点对点加密通信与文件传输桌面软件（Windows，Electron）。

版本：5.2.0.0（四位版本号，前缀一律小写 v）
appId：com.securetransfer.app，productName：安全传输
技术栈：Electron 41 + React 18 + TypeScript + Vite，electron-builder 打包（NSIS 安装器 + portable 便携版）

核心功能
--------

X25519 握手：首次下发豪密底本（Base32 随机置换表），每个会话使用不同的乱码表。

全通道 AES-GCM 加密：帧计数防重放，TOFU 指纹校验；文字消息先走豪密再进加密通道，与文件共用同一条通道。

加密强度与自定义密钥：设置里可选择 64 / 128 / 192 / 256 / 512 / 1024 位（默认 256 位）。
  128 / 192 / 256 位：单层 AES-GCM，走 AES-NI 指令集，速度最快。
  64 位：兼容通道，64 位密钥材料经 HKDF 扩展为单层 AES-128-GCM。
  512 / 1024 位：拆成 2 / 4 段 256 位密钥做级联 AES-256-GCM，密钥总长度与所选强度一致。
自定义密钥：设置页与添加好友弹窗共用同一套算法（PBKDF2-SHA512，21 万轮，固定盐）。
  留空即使用默认的 X25519 ECDH 派生密钥；填写后两端密钥必须一致，否则握手失败并提示原因。
  本机只保存派生后的种子，且经 Windows DPAPI（Electron safeStorage）加密落盘，不保存明文口令。

文件传输：64KB 分块、SHA-256 双端校验、无损保存到「下载\安全传输」。
连接保活：10s keepalive / 15s PING / 45s 判死，指数退避 3 到 30s 自动重连。
离线暂存：文字离线存入 outbox.json，上线自动重投，按消息 ID 去重。
局域网设备发现：UDP 组播 + 子网定向广播。
状态与收发：在线/离线/连接中、已读/发送成功标签、失败红框提示；拖入、文件选择器、路径输入三种选文件方式。

界面（v5 Liquid Glass）
-----------------------

参照 macOS 27 的 Liquid Glass：白底不透明窗口 + 玻璃面板（模糊 / 提饱和 / 镜面高光 / 边缘提亮 / 悬浮投影）。
左上角 macOS 风格圆形交通灯：14px 圆形、23px 中心距，悬停显示符号。
窗口外形为正圆弧，窗口四周围绕透明边距绘制真实悬浮投影；鼠标移出窗口内容区域时边距自动点击穿透。
全屏为普通矩形贴满屏幕（隐藏任务栏时铺满整屏，保留任务栏时止于任务栏上沿），不再做黑色圆角填充。
背景：30 色马卡龙预设 + 取色器，可调浓度 / 不透明度 / 毛玻璃 / 圆角 / 高光 / 投影 / 强调色。
设置窗口为双栏导航（个人资料 / 外观 / 加密 / 运行偏好 / 关于）。
侧边栏左下角常驻显示版本号与运行模式（安装版 / 便携版）。
侧边栏网络区显示固定 IPv6 / 公网 IPv4 / 本机 IPv4，点击整行复制。
首次启动显示简介页（右上角可跳过），跳过后不再出现。
按钮与提示文案参照微信、QQ、多闪等聊天软件的常见叫法。

运行模式
--------

        安装版                    便携版
托盘    可选（默认关闭）          无
自启    可选（默认关闭）          无
注册表  仅自启动 Run 键（开启时）  绝不写
关窗    按设置退出或驻留托盘      完全退出，无后台进程
数据    %APPDATA%\安全传输        exe 所在目录 Data\ 与 下载\
        下载\安全传输

便携版由 electron-builder portable 目标生成（启动器注入 PORTABLE_EXECUTABLE_DIR 环境变量，主进程据此识别），删除便携版所在文件夹即等于卸载，零残留。

构建
----

前置：Node.js 18 及以上（建议 20+）、npm 9 及以上，Windows 10/11 x64。

  npm install            首次
  npm run dist:win       构建主进程/预加载/渲染层 + electron-builder（NSIS + portable）

产物在 release\：
  安全传输-安装程序-v5.2.0.0.exe   NSIS 安装器（perMachine，默认装到 C:\Program Files\安全传输，桌面与开始菜单快捷方式；支持 /S 静默安装；含降级拦截、覆盖安装、彻底卸载）
  安全传输-便携版-v5.2.0.0.exe    单文件便携版，解压（复制）即用，关窗即退

其他常用命令：
  npm run dev             开发模式（Vite HMR + Electron）
  npm run build           仅编译三个进程
  npm run pack            只打包目录不生成安装器

构建缓存建议放到 D 盘避免占用 C 盘：
  $env:ELECTRON_BUILDER_CACHE = 'D:\.securetransfer-build\ecache'

安装器行为说明
-------------

启动时读取卸载注册表键做降级拦截（按数字段逐段比较，段数不等按 0 处理，兼容三位/四位版本号）。
若卸载键指向的程序已不存在（孤儿键），安装器自动删除该键并视为全新安装，不会误判降级。
卸载时清除：安装目录、桌面/开始菜单快捷方式、卸载注册表键、%APPDATA%\安全传输、%LOCALAPPDATA%\安全传输、下载\安全传输，以及安装时/Windows 自动生成的防火墙规则（含便携版遗留的同名规则）。
静默参数：安全传输-安装程序-v5.2.0.0.exe /S 安装；"C:\Program Files\安全传输\Uninstall 安全传输.exe" /S 卸载。
