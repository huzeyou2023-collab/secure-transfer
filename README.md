# 安全传输（SecureTransfer）

豪密 + AES-256-GCM 端到端加密的局域网/公网文字与文件传输工具。无服务器中转，数据只存本机。

本仓库按版本归档历史源码（2026-09 起，22 个版本）。归档范围：代码、配置与说明文档；node_modules、package-lock.json、二进制资源（图标/表情图）、安装包与便携版 exe 不在仓库内，完整交付包见本地备份 `D:\hzy\文件\安全传输各版本备份`。源码按拍平方式归档，同名文件以所在目录名前缀保留（如 main-index.ts = src\main\index.ts、discovery-types.ts = src\main\discovery\types.ts）。v6.1.1.0 的备份包内源码缺失（包内有说明），该目录仅存说明与许可文件。本项目依据 MIT 协议开源，仓库根目录及每个版本目录内均含 LICENSE 与《开源软件申明》（第三方组件许可）。

## 便携版通用使用说明

- 免安装：解压/复制到任意文件夹（建议 D 盘），双击 `SecureTransfer-Portable-vX.Y.Z.W.exe` 即可运行。
- 不写注册表、不留后台进程；关闭窗口即完全退出。
- 数据保存在 exe 所在目录旁的 `Data\` 与 `下载\`，换机器可整体拷贝目录迁移。
- 卸载 = 直接删除整个文件夹。
